# PDF 报告导出

报告页的“导出 PDF 报告”现在会下载真正的 PDF 文件。已生成的历史报告也可以导出，不需要重新面试。

导出内容包括综合分与原有权重、八维矢量图和各项分数、总评、薄弱点、改进清单、逐题问题和原回答、完整参考回答、重答任务、自查条件、评分依据及已保存的语音分析。没有观察依据的维度继续显示“未评估”，历史报告中不存在的参考答案不会补造。

## 操作与失败恢复

- 报告加载成功后才能导出；生成期间显示状态、禁用重复点击。
- 网络中断、网关返回 HTML、无效 PDF 或生成失败时显示持久错误，并允许点击“重试导出 PDF”。原报告保持可见，不清空面试记录。
- 桌面直接触发文件下载。手机如果打开 PDF 预览，可通过系统分享菜单保存到文件；具体行为取决于浏览器。
- 导出直接读取已保存的报告，不自动评分、不调用 AI，不改变已保存分数。

## 实现与运行依赖

- `GET /api/report/<session_id>/export` 返回 `application/pdf` 附件，并关闭响应缓存。
- 公网试用复用报告的浏览器归属检查，其他浏览器和无归属历史记录不能导出。
- 报告尚未生成或面试未结束时返回 409，生成失败时返回可重试的 503。
- PDF 在内存中生成，不长期保存用户导出副本，不需要额外浏览器进程或外部字体请求。
- `report_pdf.py` 使用 ReportLab 5.1.0。运行依赖已加入本机试用与生产部署清单。
- `assets/fonts/InterviewSans-Regular.ttf` 随项目提供，来源及 OFL 许可见同目录说明。字体子集嵌入 PDF，中文可搜索复制。图表为矢量图，长段落、长代码和参考回答可以自动跨页。
- 更新后需重启服务；桌面重新部署检查已包含新增模块。

## 验证

`tests/test_pdf_export.py` 使用独立临时数据库，验证 PDF 文件头、附件响应、内嵌字体、中文文本、八维图及复盘内容、长回答与参考回答末尾标记、零分与缺失值、原报告不被修改、无额外 AI 调用、访问隔离和失败重试。

桌面和手机浏览器均已验证真实 PDF 下载；模拟网关异常、无效 PDF 和网络中断后可重试成功；生成中重复点击只发起一次导出。

另使用 Poppler 渲染并检查标准样例和多页长回答样例，确认中文、矢量图、页码与跨页内容完整，没有裁切和重叠。样例和测试报告使用模拟数据，不代表真实用户的面试结果。

更新原公网服务后，已通过 HTTPS 实际下载可解析的 PDF，并验证其他浏览器访问返回 404。该检查只创建一条私有模拟记录，完成后已删除这条测试记录，未改动已有用户报告。
