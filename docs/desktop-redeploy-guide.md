# 桌面一键重新部署

桌面已添加 **AI面试系统-一键重新部署** 图标，双击即可使用，不需要管理员权限。

它会检查项目文件与 Python 语法，停止旧的试用服务和公网隧道，重新加载 `D:\AI_Interview_Agent` 中当前保存的代码，再建立新的公网入口。只有通过实时 HTTPS 健康检查后才显示成功、更新桌面网址，并自动打开浏览器。

完成时会显示“【4/4】重新部署完成”。此时可以关闭命令窗口，后台服务继续运行。若失败，窗口会保留错误提示；不会清空面试数据。日志保存在 `D:\AI_Interview_Agent\.public-test\redeploy.log`。

桌面还有两个自动更新的入口：

- **打开AI面试系统**：直接打开最近一次验证成功的网址。
- **面试系统-当前网址.txt**：复制其中的网址发给测试者。

重新部署会短暂中断访问，临时网址可能变化，需要重新分享；关机、休眠或断网仍会中断公网访问。已有记录保存在硬盘，重启不会删除；临时网址更换后原浏览器身份不会自动迁移。这仍是本机公网试用，并未绑定 `aiinterview.bot.cd` 或迁移到云服务器。

启动图标指向 `D:\AI_Interview_Agent\tools\一键重新部署公网试用.cmd`，实际执行 `redeploy_public_test.ps1`，继续复用已有启动与关闭脚本。没有修改 `.env` 或数据库结构。

验证结果：已实际完成重新部署并通过公网 HTTPS 和 Edge 浏览器首页/接口验证；原数据库和试用数据库的四张业务表逐项哈希比对一致；桌面快捷方式目标存在，网址文件与运行中的隧道一致；重复任务互斥测试通过。
