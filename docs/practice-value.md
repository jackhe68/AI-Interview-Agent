# 练习价值与八维报告

本次更新沿用现有面试、评分和报告请求，不额外为每个回答发起一次 AI 调用。

## 面试过程

- 点评针对刚才的具体回答指出亮点、错误或遗漏，并给出下一步改进动作。
- 点评不再在下一题出现时自动隐藏，用户可继续阅读。
- 正在追问时不展示参考答案；完成当前题及其追问后，点评可包含回答思路和参考回答。
- AI 返回格式不完整时允许重试，不将缺少下一题误判为正常结束，不保存半条回答。

## 逐题复盘

报告新增逐题复盘区：真实问题、用户原回答、当时点评、具体亮点与不足、回答思路、可展开的参考回答、重答练习任务和自查条件。

新的 AI 复盘项必须使用有效回答编号，并逐字引用对应回答中的连续原文。无效编号、编造的回答证据会被过滤，不会套到其他题目。
评分提示只提供实际问题与候选人回答，不将 AI 点评或参考答案算作候选人的能力表现。
参考回答用于学习，不应编造候选人的个人经历，也不是唯一的标准答案。

报告沿用 reports.detail 的 JSON 存储，读取历史报告不会触发自动重评分或改写旧分数。

## 八维图

| 维度 | 观察内容 |
| --- | --- |
| 专业知识 | 回答中概念与机制的准确性 |
| 回答完整性 | 对当前问题要点的覆盖程度 |
| 逻辑表达 | 回答的结构与论述清晰度 |
| 岗位相关性 | 内容与所选岗位问题的相关程度 |
| 问题分析 | 拆解问题、定位原因和比较方案的表现 |
| 实践应用 | 将知识用于具体情境并验证效果的表现 |
| 举例论证 | 使用具体示例支持结论的表现 |
| 复盘改进 | 解释验证结果、反思不足和改进方案的表现 |

前四项与原有评分一致，综合分权重保持 40%/30%/20%/10%。新增四项必须有可关联的回答原文和有效分数才能展示；未观察到的能力标记为“未评估”，不补零、不从其他分数推算。八项都有有效数据时绘制完整多边形，缺失维度只画已观察的点与相邻线段。

修复雷达图标签被后续画布清空的问题。图形采用直接绘制，避免调整窗口或截取整页时动画重置造成数据缩到中心。图下保留可阅读的数值与证据，支持手机单列布局。

## 验证

- `tests/test_practice_value.py`：逐题信息持久化、证据与回答编号过滤、零分与缺失值区分、旧报告兼容、追问后才展示参考答案、评分排除 AI 参考回答、格式异常时保留作答及桌面/手机浏览器实测。浏览器还检查实际绘制的多边形像素、标签、无横向溢出以及点评不自动消失。
- `tests/test_report_recovery.py`、原面试回归、输出长度、API 保护、候选人背景、放宽次数限制和音频分析测试通过。
- 使用临时数据库和模拟答题内容进行了两次真实 AI 调用，验证回答思路、参考回答、练习任务、自查条件和八项有依据的维度评分均能生成；未修改用户已有面试数据。
- `practice-value-mobile-preview.png` 是使用模拟 AI 响应生成的测试截图，不是真实用户的面试结果。
