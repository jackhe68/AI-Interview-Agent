# 新评估报告复核与本轮改进

核对日期：2026-11-01。本轮针对已确认的交付与阅读体验问题修改，继续保留当前宽松试用配置。

## 复核结果

- 版本化静态文件此前仍要求重新验证缓存。这项成立，适合立即优化。但手工日期参数并不等于内容指纹，不能直接给所有旧版本参数设置一年缓存。
- 生成报告时缺少可阅读内容成立。逐题点评早已在作答阶段生成并保存，等待综合报告时应先提供这些内容。
- 总评摘要用小号紫色粗体承载长文字、雷达说明使用警告样式，这些阅读与状态表达问题成立。
- 后台队列并非缺失：当前已有SQLite持久任务、事务领取、租约及单工作线程。报告生成期间不持有覆盖云端调用的数据库长事务。
- 没有发现源码引用报告列举的 `/api/auth/*`、`/api/wham`、`/api/timedtext`，不据此新增账号接口或删除正常功能。
- 字体的OS/2字重为400，内部名称仍有Thin。本轮未把名称当作字形实际为100字重的证据，也未因此切换PDF技术栈。现有PDF回归会验证中文可提取和长文完整性。
- 当前流程上限是3道主问题和各一次追问；报告中“3次作答即自动结束”与当前状态机不一致，继续通过完整流程检查验证，不改动业务规则来适配该描述。
- 语音指标需要录音及开启基础分析；没有上传音频就显示未采集，不能据此认定功能没有实现。缺少回答依据的雷达维度继续显示未评估，不强行凑满八维。
- 单点链路时延不能证明“90%瓶颈”或所有客户端都只能HTTP/1.1。正式域名、真实并发和长期性能仍需独立验证。

## 本轮实现

### 按内容版本缓存静态文件

所有模板通过统一助手生成CSS和JS链接，版本取文件SHA256的前16位。仅当请求版本与当前内容指纹相符时，静态响应设置 `public, max-age=31536000, immutable`；无版本、手工旧版本或不匹配版本仍要求重新验证。文件更新后链接自动变化。

HTML、历史API、报告API和PDF继续保持原有私有/不缓存策略，不将用户数据放入公共缓存。旧页面的脚本链接仍可正常读取。

### 等待时先读逐题点评

报告202响应立即提供当前面试已保存的问答与点评，不新增模型调用；生成失败时也可继续阅读。接口继续检查归属。前端对这些文字进行转义，只在内容变化时重新渲染，保留用户已展开的题目。

最终综合报告完成后替换临时阅读区。未完成时禁止导出PDF，保持“已保存点评”与“最终评分”的区分。

### 等待状态和阅读体验

生成中按钮显示“正在自动更新”，避免让用户误以为必须点击重试。可见页面先每2秒查询，长等待时逐步降到5/10秒；后台页面30秒查询一次，回到前台立即核对状态。单次网络读取等待15秒，独立于后台任务的生命周期，不设置一个到点就丢弃后台结果的总等待时限。

总评标题与摘要分开，正文15px、增加行距并限制段落行宽。雷达说明改为中性信息样式，加深雷达标签、警告和成功文字。首页明确语速停顿分析需录音和基础分析授权，八维评估取决于回答依据。

## 验证与边界

- 内容指纹、文件内容变化后版本变化、匹配/旧版本缓存头、304、静态响应无新增Cookie、HTML/API不缓存。
- 点评即时可读、失败后保留、跨浏览器不可访问、重复读取不新增模型调用。
- 手机与电脑的安全转义、自动更新状态、轮询中保留展开状态、最终报告切换与重访缓存。
- 原评分、后台恢复、PDF、草稿、继续面试、专业选择、键盘操作、访问隔离及宽松用量配置回归。

本轮不会承诺模型本身变快，也没有切换域名、接入登录或恢复码。正式迁移前仍需补齐部署入口的用户数据隔离。评估报告遗留会话未给出明确ID，不删除任何不能确定归属的记录。

公网复测通过：匿名和已有访问身份的静态请求均不新增身份Cookie，HTML与接口维持不缓存，浏览器重复访问静态文件本地命中。初始202响应约1.67秒带回已保存点评，真实AI综合报告随后完成并正常替换预览；其他浏览器无法访问。原有59场面试、414条对话、16份报告逐条核对未改动，临时记录已删除。耗时为本次观测，不作为延迟保证。

静态请求专门停止永久会话Cookie续期，页面和API仍按原方式续期；未调整访问身份格式或使用配额。
