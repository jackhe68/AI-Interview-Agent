# 评分依据与有效作答覆盖（practice-v4-evidence）

新生成报告采用v4规则：保持八维名称及原四项40%/30%/20%/10%权重。每个可展示的核心分必须有实际回答的连续引用、有效题目标识、评分说明，且与八维中的同维度分数一致。没有可核对依据或返回null时，该维度为未评估。任一核心维度未评估则不计算可展示综合分，不擅自重新分配权重。

跳过、空白不计有效回答，也不能作为低能力证据。报告保存有效回答、跳过、主问题覆盖数；例如一条实际回答加五次跳过，仍是一条有效回答、覆盖一道主问题。证据不足时使用保守总结，避免展示未经支持的整场能力断言。跳过题仍可保留学习用参考答案，但点评不推断能力差。

标尺在评分提示中逐维说明，并提供0至39、40至59、60至79、80至100的训练性分档依据。学历、专业、年级和声学指标不作为能力评分证据；没问到的举例、项目或复盘不默认扣分。这些约束与文字引用校验不能保证模型对所有专业内容判断正确，不能视为已证明评分准确率。

历史报告不重新生成、不改写旧分数。原版本继续读取；新版本在detail和API场次信息中保存规则版本。保留原SQLite非空数值列以兼容旧结构，未评估数值使用0占位，同时明确保存 `unassessed_core`、`overall_unassessed` 等状态。展示、历史和PDF必须使用API的nullable分数或按状态解释，不能把占位0纳入成绩统计。

测试中的数值与引用均为虚构模型输出，只验证契约、范围、零分/缺测区分、版本和恢复。`tests/scoring_cases.json` 固定九类输入，供后续人工复核/模型评估使用；目前只验证输入保留及缺少依据时不输出总分，不宣称高/中/低答案的真实模型排序已测。真实重复评分、平均值、分数波动及评语一致率尚未测量。本轮真实AI调用0次；今后真实评估需另设调用及费用上限。

无数据库表结构变更；回滚代码前需保留新报告的状态元数据，不能用只读原数值列的旧展示程序把未评估误显示为零分。更安全的回滚方式是保留v4读取兼容逻辑，仅回退生成策略；不恢复旧数据库覆盖用户新记录。
