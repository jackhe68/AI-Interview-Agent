# 专业方向与首页改版

本轮先备份当前代码、配置和数据库快照，再在独立副本中实现与验证。此前讨论的专项复练、草稿恢复、自然追问等改进另存为待办，本轮不一并实施。

## 两种入口

- 按专业找岗位：学科 → 专业 → 推荐岗位 → 难度。默认从此入口开始。
- 直接选岗位：保留原来的 Java 后端、前端开发、Python 后端、算法工程师、产品经理和数据分析六个快捷入口。旧配置恢复时仍进入直接选岗位。

专业目录转录自用户提供的院校专业截图，只用作本轮练习方向示例，不作为官方最新专业目录或就业承诺。共六大学科、44 个专业，映射到66个不重复的练习岗位。学院名用于专业下拉分组，用户无需表明自己的学校、真实专业或学历。

专业名与学院名可用于筛选。切换学科、专业或入口时清除过期岗位选择，避免提交不一致的配置。专业与岗位组合由服务端验证，客户端不能直接传入自由提示词或虚构目录。

## 面试与记录

- 选择专业会影响本场的岗位考点和追问语境。默认中文问答，外语专业在界面明确说明侧重岗位知识与情境分析。
- 专业配置不等于用户真实背景，不能据此加减分。简历资料仍为单独可选、需同意后发送的输入，不会自动填入或保存为浏览器背景表单。
- 入门场景允许课程与设想案例；艺术、音乐、舞蹈和体育方向不能假称已观察作品、演奏或动作，只评估当前回答中可观察的内容。
- `interview_selections` 为新增关联表，仅保存已确认的练习方向。原业务表和历史分数不改写，重启可恢复方向，删除面试会级联删除该配置。
- 专业在面试页、历史列表、报告和 PDF 中可见，“同配置再练”继续传递专业标识。

## 首页布局

延续现有浅色与蓝紫配色，精简主视觉并删除旧的模拟统计；突出方向选择。学科分组、专业下拉和岗位卡片逐级展开，岗位附带练习重点。手机使用双列学科/岗位和单列专业输入，更清楚地区分选中状态。原有大回答框、八维报告和 PDF 导出保留。

## 验证

- `tests/test_major_paths.py` 覆盖全部44专业合法开场、原快捷入口、无效或不匹配选择在AI调用前拒绝、方向在重启/追问/历史/报告/PDF中保留、级联删除和迁移幂等。
- 桌面和手机浏览器覆盖逐级选择、筛选、切换后清空旧岗位、保存恢复及同配置再练，无横向溢出或页面脚本错误。
- 原有 API 保护、背景隐私、放宽次数、逐题复盘、报告恢复和 PDF 导出检查通过。
- 使用隔离数据库和模拟经历对英语教师、视觉设计方向各做了一次真实 AI 验证，确认能生成对应追问或带思路与参考回答的反馈；不代表66个方向均完成真实面试质量评测。

完整备份的恢复范围和环境重装说明位于备份包内。虚拟环境、下载模型、日志与旧进程状态不属于代码/数据库快照。

上线后保留原公网网址，验证了专业目录、非法专业拦截及英语教师方向的真实 AI 开场和历史记录，完成后删除了该条测试面试。上线前后逐项核对原有两份数据库中446条面试、消息与报告记录，均未改写或丢失。
