# AI调用边界与错误恢复

所有正式/试用入口的SDK客户端显式关闭隐藏重试，保留60秒SDK超时及原输出上限。调用结果验证choices、完成状态、文字类型、空内容和编码；截断或异常结构返回明确的AI服务错误，不抛给用户内部堆栈。JSON任务只接收一个完整对象或单一JSON代码围栏，拒绝重复键、多对象拼接和任意前后说明文字，不用贪婪截取假定结构正确。

SDK超时、连接、401/403鉴权、402额度、429限流和其他服务错误按类型/状态分类。普通日志只写固定分类、状态、请求关联号或任务摘要，不写异常原文、响应正文、请求内容、密码或令牌。

仅当上游明确返回429且Retry-After为不超过2秒的短等待时，应用使用指数公式加少量随机抖动，最多重试一次。每次SDK派发都单独原子预留预算；第二次预算不足立即停止，服务端占用槽最终释放。更长等待、SDK超时、连接断开、鉴权、额度及不明错误不自动重试，避免把可能已经处理的请求再次发送。未提供或不支持的上游Retry-After采用保守60秒提示，不自动等待。关闭API保护的开发模式也没有SDK隐藏重试，但不启用这项应用层短重试。

开始请求回执与回答回执继续防止响应丢失后的重复建场/保存；应用不能撤销已经发到第三方的请求或保证第三方没有发生费用。用户看到结果待确认时，应先核对历史和恢复状态。

后台报告增加同一任务摘要的安全诊断关联。默认重试不是重复生成报告任务；报告失败仍需用户显式点击重试。前端开始请求有90秒等待保护，不把客户端中止当作服务端已取消或未保存。

10项新增服务契约测试使用真实SDK异常类型与虚构响应，验证分类、日志脱敏、非法结构、JSON歧义、异常等待标头、单次短重试、预算和槽释放。已有调用保护、Token上限、报告恢复、创建回执及浏览器流程通过；真实上游故障和模型质量未在线注入验证。
