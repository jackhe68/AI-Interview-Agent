# 草稿保护与手动查看最终报告

## 用户体验

- 回答文字按本场面试和当前题目标识独立保存在当前浏览器，保留24小时。输入、编辑和语音转写后均保存；提供清空入口。
- 刷新后先恢复本地文字，再读取当前题目状态。联网恢复时不会把上一题草稿填入新题；未提交的修改可在单独展开区查看和复制。
- 本机存储不可用时显示明确提示，不声称保存成功。录音文件与可选简历表单不纳入草稿保存。
- 回答成功后清除该题已提交草稿；结束或删除面试时清除此场草稿。完成反馈由具备浏览器归属校验的服务端接口恢复，不另外永久保存到浏览器。
- 最后一题仍由用户点击“提交回答”。成功后保留最后问题、回答思路和参考回答，不再1.8秒后自动跳走，也不提前生成评分报告。
- 看完建议后，用户手动点击“结束面试并查看报告”。刷新完成页仍能查看最后点评。提前结束时明确说明未提交文字不计分，只有结束成功才清除草稿并进入报告。

## 断网与重复提交

`GET /api/interview/<id>/state` 只读取已保存的当前题目、进度、作答数量和最后点评，不调用 AI，并沿用原浏览器归属检查。

新页面提交前核对题目标识，生成唯一提交标识。新增 `answer_receipts` 关联表，用同一个事务保存回答、语音关联、点评、下一题、进度与提交结果。响应丢失后的相同请求可返回已保存结果，重复请求不会再次写入或重新调用 AI；过期题目不能当作新题提交。正在处理的重复请求提示等待，恢复操作只读取状态，不自动再次发送回答。

进程在云端调用完成、事务保存之前中断时，尚无可恢复的提交结果，用户重试仍可能再次调用云端；数据库事务保证没有半条成功记录。原无提交标识的客户端仍兼容，新增客户端会带上完整的题目和提交标识。

本轮仅新增关联表，不改写旧面试和旧分数；删除面试时级联删除提交结果。重建会话时只还原问题与真实回答，避免把已保存的教学参考回答加入候选人对话上下文。

## 验证

- 独立临时数据库验证：响应丢失后的结果重放、重启后重放、同标识不同内容拒绝、旧题拒绝、并发重复请求、事务中途失败完整回滚、浏览器隔离、级联删除、最后点评不触发评分。
- 桌面和手机真实浏览器验证：刷新恢复、离线输入、语音转写文字保存、清空、过期、存储不可用、跨题隔离、最后点评停留超过原自动跳转时间、刷新后保留点评及手动查看报告。
- 原专业选择、背景隐私、语音关联、报告恢复与 PDF 导出回归检查通过。

- 原公网手机页面实测通过：刷新后恢复文字草稿；真实 AI 最后一题点评停留且刷新仍可见；相同提交重试只保留一份回答，并未提前生成报告。
- 上线后核对：原56场面试、391条对话和14份报告内容均未变化，临时测试记录已清理，数据库完整性检查通过。
