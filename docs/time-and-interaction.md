# 时间、进度与基础交互优化

## 时间显示

新记录统一写入带 `Z` 的UTC时间。历史与报告API输出统一带时区，网页和PDF明确显示北京时间（UTC+08:00）。面试恢复计时和报告时长按真实时间差计算，结束后计时不会继续增长。

旧记录不改写。当前Windows试用来源已核实为UTC+09:00，因此读取无时区旧记录时按该偏移转换。其他安装若导入不同来源的旧数据，可通过环境或 `.env` 中 `LEGACY_TIMEZONE_OFFSET` 指定原始偏移，例如 `+08:00`。不能根据读者所在地猜测旧数据来源。

历史列表按转换后的实际时间排序，避免旧本地时间字符串与新UTC字符串混排。已有面试内容、成绩和原始时间字段保持原值，背景资料与语音分析的到期机制继续使用原来的数值时间。

## 进度与操作

- 顶部明确“当前主问题1/3”，单独显示“首轮作答”或“追问中”。进度包含主问题及其追问共六次作答阶段，最后一次作答结束显示100%。结束前仍由用户手动进入报告。
- 录音、提交和AI分析状态在操作区域更新，不再覆盖题目阶段。进度条提供读屏数值，题目变化可由辅助技术读取。
- 回答框有持续可见且关联到输入框的标签；加深辅助文字和主要按钮颜色，补充键盘焦点样式。
- 结束确认窗口提供对话框语义、标题及说明，打开后聚焦“继续面试”，Tab在窗口内切换，Esc关闭后回到原按钮。关闭时从辅助技术可见范围中隐藏，背景在打开期间不可操作。
- 结束请求处理中防重复操作；网络失败或超时在确认窗口内持续显示，保留草稿，允许重试。超时不会声称结束一定失败。
- 首页启动失败、历史加载及删除异常提供可手动关闭的持续提示；加载失败不会被呈现为没有历史记录。常规成功提示仍为简短通知。

## 验证

- UTC和旧时间转换、跨日显示、新旧混合时间排序、旧记录不改写、混合格式的作答时长。
- 浏览器位于其他时区时仍明确显示北京时间。
- 手机与电脑的主问题/追问阶段、键盘焦点循环与恢复、Esc关闭、异常提示停留、草稿保留。
- 原后台报告、报告重试、PDF、面试流程、草稿、专业选择、背景、语音关联及访问隔离检查。

公网检查通过：新测试记录写入UTC，历史页面明确显示北京时间，追问阶段进度、输入标签、确认窗口焦点切换与Esc返回正常。本轮测试未新增AI调用。更新前55场面试、407条对话、15份报告的原始内容逐条核对无变化，临时记录已清理。
